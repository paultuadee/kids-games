# บ้านเกมเด็กเก่ง

เกมสำหรับเด็กอนุบาล 3 เกม เปิดเล่นได้ในเบราว์เซอร์ ไม่ต้องติดตั้ง

- `detective.html` นักสืบตัวจิ๋ว — ดูภาพ หาคนซน (ระดับ 1) และเรียนรู้มารยาท (ระดับ 2)
- `hero.html` แต่งตัวฮีโร่ — ออกแบบฮีโร่ของตัวเอง
- `colors.html` ห้องทดลองผสมสี

เปิดใช้ผ่าน GitHub Pages: Settings › Pages › Deploy from branch › main / root
